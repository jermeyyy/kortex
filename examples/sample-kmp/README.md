# Sample KMP Project

This is a minimal Kotlin Multiplatform project for testing Kortex features.

## Structure

- `src/commonMain`: Shared code
- `src/androidMain`: Android-specific code
- `src/iosMain`: iOS-specific code

## Usage with Kortex

1. Onboard this project:
   "Onboard the project at examples/sample-kmp"

2. Try symbol navigation:
   "Where is the Platform class defined?"

3. Try cross-platform navigation:
   "Show me the iOS implementation of Platform"
